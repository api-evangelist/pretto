# Pretto

> Pretto is a French online mortgage brokerage operated by FINSPOT SAS (Paris, founded 2016).
> It runs a digital platform for simulating a home loan, comparing rates across 125+ partner
> banks, assembling a financing file and working with a human credit expert through to
> signature, on a published, non-negotiable fee schedule. Pretto Galaxie opens the same
> technology to independent brokers, and Pretto Search is a property-search product priced
> against real borrowing capacity.

## Status of the API surface

Pretto publishes **no public API and no developer program** as of 2026-08-17. Agents should not
expect a callable Pretto endpoint. What exists, and what it returns anonymously:

- `https://api.pretto.fr/api-docs` — HTTP **401**, `WWW-Authenticate: Basic`. An API reference
  route genuinely exists on the API host but is behind HTTP Basic auth. Control paths on the
  same host (`/api-docsX`, `/zzz-nonexistent`) return 404, so the 401 is a real gate, not a
  catch-all.
- `https://developers.pretto.fr/` — HTTP **302** to `/inactive`, which returns **401**. A
  ReadMe.io developer hub subdomain is provisioned but deactivated.
- No OpenAPI, Swagger, AsyncAPI or GraphQL document is served on any Pretto host.
- No `/.well-known/` document of any kind (security.txt, openid-configuration, api-catalog,
  ai-plugin.json, agent-card.json) — every path returns 404.
- No MCP server and no A2A agent card.

## Code

- npm scope `@pretto`: `@pretto/picto` (icons), `@pretto/places` (address autocomplete),
